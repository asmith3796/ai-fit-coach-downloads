# AI Fit Coach Android downloads

Download the signed Android installer from [Releases](https://github.com/asmith3796/ai-fit-coach-downloads/releases). AI Fit Coach requires an invitation and an existing coaching account to sign in.

Current release: **1.0.0 (3)**. Open the APK in Chrome on Android, then install it over the existing app. Keep the app installed to retain its sign-in and pending work. TestFlight is for iPhone; it is not used for this Android installer.

This repository contains distribution information and release installers.
