# AI Fit Coach Android downloads

Download the signed Android installer from [Releases](https://github.com/asmith3796/ai-fit-coach-downloads/releases). Sign in with a phone verification code. Existing email invitations remain supported.

Current release: **1.0.0 (20)**. [Download Android build 20](https://github.com/asmith3796/ai-fit-coach-downloads/releases/download/android-1.0.0-build20/AI-Fit-Coach-1.0.0-build20.apk). Open the APK in Chrome on Android, then install it over the existing app. Keep the app installed to retain its sign-in and pending work. TestFlight is for iPhone; it is not used for this Android installer.

This repository contains distribution information and release installers.
